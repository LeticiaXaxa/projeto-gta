# 📌 Sobre o projeto

O projeto GTA é uma aplicação web que permite ao usuário selecionar uma foto própria e 
transformá-la em um personagem inspirado no estilo artístico de GTA.

# 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Puter.js (IA)

# ⚠️ Observações sobre a geração de imagens

A transformação das fotos depende do serviço de inteligência artificial disponibilizado 
pelo Puter.js. Pode ser necessário entrar em uma conta, e a geração está sujeita aos limites
e às condições de uso do serviço. Caso esses limites sejam atingidos, a geração de imagens
poderá ficar indisponível.
